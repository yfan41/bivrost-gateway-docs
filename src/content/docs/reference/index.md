title: "四、补充说明"
---

本章包含名词解释、命令格式、集群故障切换与 MCP 服务四部分：

- [4.1. 名词解释](/reference/glossary/)：机台 OEE 数据、机组 OEE 数据、机组加工计数等概念的定义与计算方式。
- [4.2. 命令格式](/reference/command-format/)：PLC 数据任务、前置条件、任务间隔、后处理（$DA$ / $POST$ / $MOCK$）、外部 PLC 数据任务、外部机台、受保护 API 与授权 API 等命令的格式说明。
- [4.3. 集群故障切换（选装）](/reference/cluster/)：共享备机池的工作方式、组建步骤、切换与回切行为、强制接管，以及不在复制范围内的内容。
- [4.4. MCP 服务](/reference/mcp/)：网关内置 MCP 服务端的开启方式、鉴权、云平台调用与客户端配置，供 AI 客户端以自然语言查询机台数据。
